# Changelog

### **2.7.0** - *July 30, 2026*
  - Fix: Nocturnal timelines and bucket boundaries remain aligned across daylight saving transitions.
  - Docs: document elapsed and calendar granularities plus Ruby, Elixir, and Go compatibility.

### **2.6.0** - *July 22, 2026*
  - Feat: synchronous, gzip-compressed Trifle Projects API driver for Track and Assert.

### **2.5.0** - *July 14, 2026*
  - Feat: Atomic PG upserts
  - Feat: Beam?Scan status ops
  - Fix: Context propagation
  - Fix: Bulk/Pipelined reads
  - Chore: Process 
  - Chore: Version Major/Minor version parity between languages

### **0.0.0** - *July 5, 2026*

  `triflestats` 0.0.0 was published to the plugin repository for the first time. Most of the drivers and compatibility is there and its been used internally with `trifle-cli`.
