# Changelog

### **2.0.0-rc.1** — *Unreleased*

- Initial Elixir implementation of Trifle.Traces.
- Supervised tracers with process-local convenience and explicit Task propagation.
- Nested results, state, tags, artifacts, callbacks, and error-safe wrapup.
- Live and deferred persistence through Postgres, Mongo, S3, File, Memory, and Null drivers.
- Shared Ruby/Elixir PostgreSQL JSONB schema with Ecto Repo reuse, indexed
  search, deterministic pagination, and scheduled retention cleanup.
- Ruby-compatible records, payloads, search cursors, counters, and retention.
- Phoenix, Plug, and Oban integrations.
